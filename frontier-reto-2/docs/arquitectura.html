Ya descubierto

El último campo de cada mensaje es un dígito de control MOD 97, de la familia del IBAN. La fórmula reproduce los 20 ejemplos y fue la única que lo logró entre unas 40 000 variantes probadas offline. 20 / 20

texto = MAYÚSCULAS(mensaje sin el control) solo letras y dígitos (se descartan ; y -) N = letras A=1 … Z=26, dígitos igual, + "00" control = (98 − N mod 97) mod 97 PING → 16 9 14 7 · 00 → 16914700 mod 97 = 34 → 98 − 34 = 64 ✓ "PING;64"

Rarezas que el clon debe copiar tal cual

  • "status":"recieved", con el error ortográfico.
  • cuentaId en ALTA, pero cuenta_id en CONSULTA.
  • "comando desconocido " lleva un espacio al final.
  • Repetir ANULA devuelve 200 con ok:false, no un error.
  • El comando no distingue mayúsculas: CONSULTa funciona.

Stack: Python en Render

Python 3.12 + Starlette/FastAPI en modo crudo. Un solo lenguaje para el harness, el fuzzer, el reproductor y el servidor, que comparten el mismo core/. Sus enteros de precisión arbitraria calculan el MOD 97 sin trucos. El modo crudo (Request directo y ruta comodín) evita los 422 automáticos de FastAPI, que no coinciden con los del original.

Sin LLM dentro del clon. Agregaría latencia y respuestas que no se repiten; el problema es determinista.

Regla de paralelismo

Un token, un solo agente contra el original. Dos agentes con el mismo token se borran el estado con cada /__reset y contaminan el log.

Los agentes en paralelo se usan para trabajo offline: uno implementa el núcleo, otro prepara el deploy y el validador de la spec, mientras el dueño del token explora.
